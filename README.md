# mini-fts\n\nA **local full-text search engine** over a directory of text / markdown files.\n\nPipeline:\n\n```\nfiles → tokenize → postings (term → {docId, tf}[]) → BM25 rank → snippets\n```\n\nThis is the same inverted-index shape used by Lucene, minus the 400k lines of Java. Good for:\n\n- personal knowledge bases\n- log / doc search on a single box\n- explaining IDF, document length normalization, and incremental reindex in interviews\n\n## Features\n\n- Unicode-aware tokenizer (letters + digits, lowercased)\n- Small English stopword list (optional)\n- Inverted index persisted as JSON (swap for SQLite FTS5 later)\n- **BM25** ranking (`k1=1.2`, `b=0.75`)\n- Phrase-ish AND of query terms (all terms must appear)\n- Incremental updates when a file changes\n- HTTP `GET /search?q=`\n\n## Usage\n\n```bash\nnode src/cli.js index ./corpus\nnode src/cli.js search 'write ahead log'\nnode src/server.js          # :8790\n```\n\n```js\nimport { Index } from 'mini-fts';\nconst idx = await Index.load('./data/index.json');\nconsole.log(idx.search('circuit breaker', { k: 10 }));\n```\n\n## Scoring\n\n```\nscore(d,q) = Σ idf(t) * tf(t,d) * (k1+1) / (tf(t,d) + k1 * (1-b + b * |d|/avgdl))\nidf(t)     = ln( (N - n(t) + 0.5) / (n(t) + 0.5) + 1 )\n```\n\n## License\n\nMIT\n
